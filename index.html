Soluzione dell'Equazione di Laplace nel Semipiano

Consideriamo il problema al contorno di Dirichlet per l'equazione di Laplace nel semipiano superiore $\mathbb{R}^2_+ = \{ (x, y) \in \mathbb{R}^2 : y > 0 \}$. Cerchiamo una funzione armonica $u(x, y)$ tale che:

$$\begin{cases} \Delta u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0 & \text{per } y > 0 \\ u(x, 0) = f(x) & \text{per } x \in \mathbb{R} \end{cases}$$
Teorema (Nucleo di Poisson). Se la funzione $f \in L^1(\mathbb{R})$ è continua e limitata, l'unica soluzione limitata è data dalla convoluzione di $f$ con il nucleo di Poisson $P_y(x)$:
$$u(x, y) = (f * P_y)(x) = \frac{1}{\pi} \int_{-\infty}^{+\infty} \frac{y}{(x - \xi)^2 + y^2} f(\xi) \, d\xi$$

Applicando la trasformata di Fourier rispetto alla variabile spaziale $x$, definiamo $\hat{u}(\xi, y) = \mathcal{F}_x[u(x, y)](\xi)$. L'equazione differenziale alle derivate parziali si trasforma in un'equazione differenziale ordinaria del secondo ordine:

$$\frac{d^2 \hat{u}}{d y^2}(\xi, y) - 4\pi^2 \xi^2 \hat{u}(\xi, y) = 0$$

Imponendo la condizione di limitatezza per $y \to +\infty$, scartiamo l'esponenziale divergente ottenendo $\hat{u}(\xi, y) = \hat{f}(\xi) e^{-2\pi |\xi| y}$. L'antitrasformata restituisce direttamente il nucleo desiderato. Il termine $e^{-2\pi |\xi| y}$ garantisce la convergenza dell'integrale.
